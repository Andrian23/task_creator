# Upwork Project Tracker

Розширення пасивно читає вже завантажений DOM сторінки Upwork Messages і передає нові повідомлення у backend цього репозиторію.

Воно не використовує Upwork API, не клікає, не переходить між чатами, не прокручує сторінку, не оновлює вкладку і не змінює DOM.

1. Відкрийте `chrome://extensions` і ввімкніть Developer mode.
2. Натисніть Load unpacked та виберіть `extension/upwork-tracker`.
3. У налаштуваннях розширення вкажіть URL Vercel deployment.
